One-time setup

This page needs a GitHub access key to publish. It is stored only in this browser, on this device — it is never part of the website, so nobody visiting your site can see or use it.

  1. Open github.com → fine-grained access token.
  2. Under Repository access, choose Only select repositories and pick this site's repository.
  3. Under Repository permissions, set Contents to Read and write. Leave everything else alone.
  4. Click Generate token, copy it, and paste it below.
