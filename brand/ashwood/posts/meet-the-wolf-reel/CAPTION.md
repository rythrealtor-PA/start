## Posting tips

- Add a trending sound inside Instagram/TikTok (soft cinematic or piano works best). The file is silent on purpose, so no music licensing issues.
- Cover: use the first frame (hook text) so it reads in the grid.
- Pin a first comment: "Which detail did you catch first: the sunrise, the fade, or the mountains? 🐺"
- Post the carousel 2–3 days after the reel so people who saw one get the other.
- Want edits? Change the text in `source/reel_template.html` and re-render (`python3 build.py && node shoot.js frames 30 23 frames`, then ffmpeg). Canva's upload tool does not accept video files, so to edit in Canva, drag the MP4 into a Canva video design yourself.
